1. What is a Variable?

In Python, a variable is like a labeled container that stores a value in computer memory. Unlike languages such as C++ or Java, Python uses dynamic typing — you don't have to declare the type ahead of time; Python figures it out automatically!

# Creating variables in Python
user_name = "Dhanush"
user_xp = 100
level = 1
is_active = True

print(f"Learner: {user_name} | Level: {level} | XP: {user_xp}")
Output:
Learner: Dhanush | Level: 1 | XP: 100

2. Core Data Types in Python

  • str (String): Text enclosed in single or double quotes, e.g. "Z-Code"
  • int (Integer): Whole numbers without decimal points, e.g. 42, -7
  • float (Floating Point): Numbers with decimal precision, e.g. 3.14, 99.99
  • bool (Boolean): Logical truth values — either True or False
  • list: Ordered, mutable collections of values, e.g. ["Python", "JavaScript", "Rust"]

3. Variable Naming Conventions (PEP 8)

  1. Variable names must start with a letter or underscore (_), never a digit (e.g. 2name will produce a syntax error).
  2. They can only contain letters, numbers, and underscores (a-z, 0-9, _).
  3. Variables are case-sensitive: age, Age, and AGE are three completely different variables.
  4. Use snake_case for multi-word variables (e.g., total_quiz_score).
